# HW Design Brief: Dual-Target SWD Flasher + UART Bridge with DUT Isolation (Phase 1)

(Original brief as provided by the user, 2026-10-21. Resolved decisions are in `architecture.md`.)

## 1. Functional description
The tool sits between a host PC (USB-C) and a DUT carrying two MCUs: an STM32 and an nRF5340.
It does three things:
1. Programs both MCUs over two independent SWD ports (nRF5340 app + network core through one port).
2. Bridges the DUT's UARTs to the host.
3. On command, electrically disconnects every DUT-facing signal, so the DUT's current can be
   measured with an external power analyzer (µA and sub-µA range) without leakage through the tool.

Operating states per channel:
- ISOLATED (default at power-up/reset): all DUT lines open, VIO off, no load on the DUT.
- CONNECTED: VTref detected, VIO tracking, SWD and/or UART groups closed.
- Mixed: UART and SWD groups switch independently (e.g. UART connected, SWD isolated).

Typical production sequence:
detect VTref -> set VIO -> close switches -> program STM32 + nRF5340 -> end debug session ->
pin reset or DUT power cycle -> open switches -> external power measurement.

The host sees the tool as a USB network adapter; each UART, each SWD channel and the control
interface is a TCP port.

## 2. Scope
- Phase 1 (this design): 2 SWD ports, UART channels, isolation switching, VTref sensing,
  level translation, USB host link.
- Phase 2 (reserve resources only, do not populate): Ethernet, BLE-to-Ethernet gateway.

## 3. Architecture
- Controller: Espressif ESP32-S3-WROOM-1-N16 (dual-core Xtensa LX7 240 MHz, 16 MB quad flash,
  no PSRAM, pre-certified). Metal enclosure: ESP32-S3-WROOM-1U-N16 (U.FL antenna connector).
  Rationale: native USB-OTG (no USB-UART bridge chip), one core for SWD bit-bang via dedicated
  GPIO, the other for USB/host, 16 MB flash for target images and OTA, very common part.
- Two identical, target-agnostic channels: A (STM32 by convention) and B (nRF5340).
  Signal chain per channel:
  VTref sense -> VIO tracking rail -> level translators -> isolation switch -> ESD -> DUT connector
- Host link: USB 2.0 FS on USB-C, enumerating as CDC-NCM (USB network adapter).

## 4. ESP32-S3 constraints for the pin map
- 3 hardware UARTs, all for the DUT (tool console runs over the network link). A 4th DUT UART
  needs an SPI-to-dual-UART bridge (e.g. NXP SC16IS752). SWO, if used, also needs a UART RX
  or RMT input.
- USB-OTG endpoint budget allows at most 2 CDC-ACM ports, hence CDC-NCM.
- Reserved: GPIO19/20 (USB D-/D+). Strapping pins GPIO0, GPIO3, GPIO45, GPIO46: not for
  isolation EN lines or anything that must be defined during boot. N16 has no octal PSRAM,
  so GPIO35–37 are free.
- SWD via dedicated-GPIO bit-bang; SWCLK/SWDIO/DIR of both channels in one dedicated-GPIO
  bundle (any GPIO via the matrix). Keeps SPI2/SPI3 free for the UART bridge and a future W5500.
- VTref sense on ADC1 pins (GPIO1–10). No on-chip DAC: VIO fixed modes via switched feedback
  resistors, PWM+RC or an I2C DAC.
- Slow signals (isolation EN, VIO mode select, LEDs) may use an I2C GPIO expander that powers
  up with all pins as inputs (e.g. TCA9555); hardware pulls keep switches OPEN by default.
- BOOT (GPIO0) and RESET buttons: tool firmware is flashed over the same USB-C in ROM
  download mode.

## 5. Signals per channel (DUT side)
| Signal      | Direction (tool view)     | Notes                                         |
|-------------|---------------------------|-----------------------------------------------|
| VTref       | in                        | DUT I/O voltage; reference only, not a supply |
| SWCLK       | out                       |                                               |
| SWDIO       | bidirectional             | direction pin driven by MCU                   |
| nRESET      | open-drain out + readback | never driven high                             |
| SWO         | in                        | optional [CONFIRM]                            |
| UART1 TX/RX | out / in                  | console                                       |
| UART2 TX/RX | out / in                  | optional; 3 UARTs total native [CONFIRM]      |
| GND         | -                         | common ground                                 |

## 6. Electrical requirements
- DUT I/O range 1.6–3.6 V, independent per channel.
- SWD: design signal path for 10 MHz (typical use 2–8 MHz). UART: >= 1 Mbaud.
- VIO per channel generated by the tool, tracking VTref within ±50 mV, >= 20 mA.
  Firmware-selectable fixed 1.8 V / 3.3 V when VTref is absent.
  VTref input bias <= 10 nA; VTref never supplies translator current.
  Acceptable simplification if justified: translator DUT-side supply from VTref through
  the isolation switch; then document static and dynamic load on DUT VDD.
- Translators: direction-controlled dual-supply buffers with partial-power-down (Ioff),
  e.g. SN74LVC1T45 / SN74AXC1T45 class. No auto-direction translators (TXB/TXS): their
  one-shots and pull-ups misbehave on SWD turnaround.
- nRESET: open-drain driver (NMOS or OD buffer) plus readback input.
- 22–47 Ω series termination on SWCLK/SWDIO at the driver.
- Pull resistors only on the tool side of the isolation switch.

## 7. Isolation switch (key requirement)
- Between translators and connector; opens every DUT-facing line, including VTref sense
  and nRESET.
- Enable groups per channel: SWD group (SWCLK, SWDIO, nRESET, SWO), UART group, VTref.
  VTref closes first; signal groups close only after VIO is valid.
- Defaults to OPEN at power-up, reset, brown-out and whenever firmware is not running
  (hardware pull on every EN line).
- Bidirectional, powered-off protection to >= 3.6 V (unpowered tool must not back-power
  or load the DUT), Ron <= 10 Ω, Con <= 10 pF.
- Leakage budget in isolated mode, per channel, summed over all lines
  (switch off-leakage + ESD + PCB): <= 10 nA typical, <= 100 nA worst case at 25 °C.
  Deliver a leakage budget table from datasheet values.
- No back-powering in any combination of tool on/off x DUT powered/unpowered x
  connected/isolated.
- Candidate: TI TMUX1574 (4 channels, EN pin, 1.8 V logic, powered-off protection up to
  3.6 V, low capacitance). Verify off-leakage at operating conditions; equivalents with
  powered-off protection are acceptable.

## 8. ESD
At the DUT connector: GND-referenced, ultra-low-leakage TVS, Cj <= 1 pF.
No VCC-referenced steering arrays (they back-power through the rail).
If ESD parts sit on the DUT side of the switch, include their leakage in the budget.

## 9. DUT power and measurement mode
- After a debug session the DUT must leave debug-interface mode: nRF5340 needs a return to
  normal mode plus a pin reset; on most STM32 families DBGMCU debug bits survive a system
  reset (cleared by power-on reset). nRESET control is mandatory; a firmware-controlled
  DUT power cycle is recommended [CONFIRM].
- Optional DUT power switch must add no leakage or quiescent current to the measured path:
  place it upstream of the power analyzer, or use a relay / PhotoMOS driven from the tool
  rail. Load switches like TPS22916 have ~10 nA off-leakage but ~0.5 µA Iq when on, drawn
  from the measured supply.
- Assume high-side current measurement with common GND. If a low-side shunt is used,
  tool GND must not bypass it [CONFIRM].

## 10. Connectors [CONFIRM]
- Per channel: ARM Cortex 10-pin 1.27 mm (VTref, SWDIO, SWCLK, SWO, nRESET, GND)
  plus UART header.
- Optional combined fixture connector carrying both channels (pogo-pin fixtures).
- Host: USB-C.

## 11. Power
- Input: USB-C 5 V. Rails: 3.3 V system (>= 500 mA for module RF peaks in Phase 2),
  VIO_A, VIO_B.
- Phase 2 option: 12–24 V or PoE input [CONFIRM].

## 12. Phase 2 reservations
- Ethernet: ESP32-S3 has no Ethernet MAC. Keep an SPI bus + INT + RST free for a W5500
  and board area for RJ45 with magnetics.
- BLE: on-module (BLE 5.0, LE only). PCB antenna at board edge with the module keep-out
  from day one.

## 13. UI and test access
- LEDs per channel: VTref present, connected/isolated, busy/error.
  One push button (start / isolate).
- Test points: VTref (tool side), VIO_A/B, SWCLK/SWDIO (tool side), isolation EN lines, 3.3 V.

## 14. Layout notes
- Short SWD/UART traces over solid GND, no stubs; DUT cable <= 20 cm.
- Leakage-critical nets (DUT side of the switch, VTref sense): washed boards, no flux
  residue, guard traces where useful.
